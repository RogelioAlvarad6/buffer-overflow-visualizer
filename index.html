Stack Buffer Overflow Visualizer

A safe, interactive teaching tool. Type input into a fixed-size stack buffer and watch what happens when it exceeds the buffer's capacity and spills into the saved frame pointer and the return address — then turn on a stack canary and watch the same overflow get caught. No real exploit or payload, just the memory layout.

      Educational use only. This tool illustrates why unchecked
      copies are dangerous, how a fixed-width buffer sits next to
      critical control data on the stack, and how two defenses respond:
      bounding the copy with strncpy() prevents the
      overflow outright, while a stack canary detects
      it and aborts before the corrupted return address is ever used. It does
      not generate shellcode, payloads, or any real attack.
